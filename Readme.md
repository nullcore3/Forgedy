# <img width="40" height="40" alt="icon-no-bg" src="https://github.com/user-attachments/assets/c33881e2-dc1a-43cb-8151-eaf2c3b92ef3" /> Forgedy

**Forgedy is a modular development toolkit designed to streamline workflows, have every tool you would ever need in one place and simplify complex development processes.**

It acts as a collection of utilities that improve productivity and provide fast, flexible tools for developers.

---

## ✨ Features

- Image Utils
- Video Utils
- Text Utils
- Code Utils
- Audio Utils
- Custom Themes

---

## 🎯 Purpose

Forgedy is built to reduce friction in development workflows by combining commonly needed tools into a single environment.

Instead of switching between multiple apps or advert-filled websites, Forgedy centralises everything in one place.

---

##  🚀 Installation

#### Find the latest release here: 

https://github.com/nullcore3/Forgedy/releases

#### Or, for the latest version:

```Shell/Bash
git clone https://github.com/nullcore3/Forgedy.git
cd Forgedy
```

And to run it:

```Shell/Bash/Any
cargo r
```
